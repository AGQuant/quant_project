1 · What this ref inherits

Assembled, not invented

Every rule below already exists. The reference cites where, so CC can check the source instead of trusting this page.

  • 9016 pattern 1 — stat tiles, uppercase muted section labels, trajectory tables. Card interiors start from this component language.
  • 9016 pattern 2 — shared components are built once and imported. results_card.js, the fib renderer, the volume three-tile row, the C-A-R-D header strip and the Check renderer are all imported by mobile. Rebuilding any of them for phone is a spec violation, not an optimisation.
  • 9016 pattern 7 — a missing value renders --. Never a fabricated 0.0.
  • 9016 pattern 9 — no page navigation for in-context actions. A card opens in place or as a bottom sheet. Tapping a card never leaves the stack.
  • 9016 pattern 12 — text-heavy cards (Live News, Results) use the shared section separator: 1px rule, uppercase muted label, 1.55 line-height.
  • 15913 — 768px breakpoint, no horizontal tab row below it, 44×44px tap targets, skeletons sized to final height, every surface carries at least one PRIMARY.

4 · State rail

Four states, told apart by shape

Reading the rails down the stack tells you the book without opening anything. Opacity alone is never the difference — colour-blind and bright-sunlight use both break that.

LIVE — solid, breathing. Data is inside its own cadence window and the market is open.
STALE — long dashes, still. Past its window. The chip always states the age, never just the word.
CLOSED — short dots. Market shut, or the gate is closed. Not a fault. Reads “last session 15:30”.
REFERENCE — short solid bar, inset. Static spec content. Can never be stale. Matrix only.
After 15:30 nothing is STALE. Outside market hours every live card flips to CLOSED and reads “last session 15:30”, not an amber warning. A dashboard that cries stale every evening trains the user to ignore the colour, and then it fails silently on the one morning it matters.

6 · Rules for the build

Five things that will otherwise go wrong

1 · A basket card's state comes from the engine tick, never from its last signal. Buy Reversal last fired at 09:45. At 14:15 that is four and a half hours ago, and a naive “age of newest row” rule would paint it STALE or dead. It is neither — it is live and quiet. State = engine tick recency, shared by all four basket cards. Signal age is a separate, smaller line in the sub-title.
2 · Never read v8_filter_state.enabled for the state chip. All six rows in that table currently say enabled = false, while four baskets wrote signals today and 21 positions are open. The engine does not consult it. A card wired to that column would render every basket OFF during a live session. Basket state derives from v8_qualified write recency plus the engine tick. (That table looks abandoned — worth its own cleanup card, out of scope here.)
3 · Zero is not missing. A basket that genuinely qualified nobody shows 0 signals with a CLOSED rail. A payload that failed to arrive shows -- with a STALE rail. These are different facts and must look different. 9016 pattern 7 forbids the fake zero, not the true one.
4 · All age maths in IST. v8_metrics.computed_at and v8_qualified.signal_ts are naive IST since cc#855. An age that comes out at exactly 330 minutes is the UTC offset, not an outage. Compare like with like before painting anything amber.
5 · Live News header must use the newest article, not the fetch clock. The desktop page prints the browser's own refresh time. That is when the phone asked, not how fresh the data is — a dead feed still shows a fresh clock. The mobile header states the newest published_at.

Do not touch

  • TAB_ORDER and TAB_LABELS stay exactly as they are. Mobile reads them; it does not edit them.
  • Dormant panel indices 3, 6, 10, 13, 14, 16, 17 keep their label slots. Renumbering breaks every deep link.
  • The desktop DOM above 768px is unchanged. This is an added layer, not a rewrite.
  • Shared components are imported. If a phone version of results_card.js appears in the diff, the card is wrong.
7 · Open for the founder

Three calls this ref cannot make

  • Master is one card or four? Master holds the mood gate, the four P&L tiles, the position ladder and the sector strip. As one card it is the heaviest thing in the stack. As four cards — Gate, Book, Realised, Sectors — the stack starts to explain itself. R3 draws it as one; splitting it is a one-line change to the tier map.
  • Raw Data on a phone. Seventeen metric columns over 208 symbols. It is tiered TERTIARY here, but the honest option is to leave it desktop-only and say so on the card rather than ship a table nobody can read.
  • Matrix as a card at all. It is static strategy documentation. It may belong behind the model launcher rather than in the trading stack.
