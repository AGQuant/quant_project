## Root cause of the "document-shaped tile"

The board row's score tile was `<div class="v"><div class="n">96</div><div class="c">rev 63</div></div>`. The shared `mobile_app.css` (`mobile_endpoints.MOBILE_CSS`) carries bare rules for exactly those names: `.v{position:relative;background:var(--panel2);border:1px solid var(--line2);border-radius:…}` with `.v::before{…width:3px;background:var(--vc,var(--amber))}` (the lavender tile with the thick left bar), and `.c{background:var(--panel);border:1px solid var(--line);border-radius:14…}` with its own `.c::before` bar (the white document shape inside it). `.row` (flex, its own padding and top border), `.tag` (mono 8.5 px) and `.big` leak the same way. Proven in the harness: a probe element with the bare class `v` gets `border 1px`, a filled background and a `::before` pseudo-element from the shared sheet. Every class this page renders is now `iv-` prefixed, and the hero's value cells, which were also `.v`, are `.iv-cv` (their content and layout unchanged).

## What shipped

**Page order**: hero (unchanged content) → TRACK toggle (unchanged) → **OPEN POSITIONS** (cards) → **CLOSED POSITIONS** (cards) → ENTERS NEXT RUN (unchanged copy) → BOARD (rows reformatted) → the rule card → the research note.

**Open positions** — the TC Scanner open-row idiom: left = symbol (bold) + track pill (MOMENTUM in brand, REVERSAL in accent) + "entered 25 Aug · score 91"; a "cmp 1077.50" line (or "cmp — · no price"); right = net % signed in win/loss colour, bold, with "day ±x.x%" small under it; a win/loss/neutral edge bar. Header line: "**N** open · avg net **±x.xx%** · table ›" from `positions.open_avg_net_pct`. Sorted net % descending. Empty: "Nothing open / No open position right now." One wording note against the spec: the spec's empty line says "on this track", but `positions.open` is the whole scanner book (both tracks — the endpoint does not filter it by the board's track, and the hero's "N positions open" counts the same book), so the pill on each card carries the track and the line does not claim a per-track book. Same reason the sheet's title is "Open positions · N" with "both tracks" in its meta line rather than the track name.

**The holdings sheet** — tap any open card, or the section header: the shared bottom-sheet component (fixed, 78vh, drag handle, backdrop / back button / Escape close it, body scroll locked while open, the history entry pushed before the lock — the cc#2159 lesson) titled "Open positions · N", meta "both tracks · avg net ±x.xx% since entry · tap a header to sort", then a horizontally scrollable table **Name · Track · Entered · Entry · CMP · Day % · Net % · Entry score** with a sticky Name column; default sort Net % desc, tap a header to sort, again to flip; Name opens Check. Rows come from the same payload, no second fetch. A track switch under an open sheet redraws the table from the fresh payload.

**Closed positions** — the same card idiom: symbol + exit-reason pill + "exited 15 Sep · momentum 64.4 < 75.0"; "entry 85.60 → exit 79.56"; right = net % bold with "net" under it. The pill: TARGET (win) / SL (loss) / TIME (muted) as the spec lists; the engine's own reasons are longer sentences ("momentum 64.4 < 75.0", "alpha −5.4 pct vs NIFTY500"), so those get a short muted word — SCORE for a score exit, ALPHA for the alpha stop — with the full reason on the sub line. Header "**N** closed · record **25%** · 1 of 4 wins" from `record`. The latest 6 cards (the payload is already newest first), then "View all N ›" → the same sheet with the closed table **Name · Exited · Reason · Entry · Exit · Net %** (default Exited desc). The payload caps closed at 20: when `closed_total` > 20 the sheet says "Showing the latest 20 of N." A closed card is tappable too (it opens the same closed sheet — a dead tap on a card is the cc#2025 lesson).

**Board rows** — content unchanged (symbol, HELD / ENTERS / GATED pill, band, GVM, gates dots, month %); the tile is a plain bold score top-right with "rev 63" (or "mom N" on the Reversal track) as a small muted line under it: no box, no bar, no background. Rows still link to Check.
